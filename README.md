# ATM10服务器：内存要多少、整合包怎么一键开服，新手从选配置到和朋友联机的实用指南

搜「ATM10服务器」的人，卡点通常很一致：知道 All the Mods 10 好玩，但不确定它到底要多大内存、服务端文件去哪下、开服之后怎么让朋友进来。更常见的情况是，看着面板服写着"支持整合包"，买了 2核4G 回来，两百多个 mod 的包连主界面都进不去。

下面按真正开服的顺序把这些事拆开：先看 ATM10 到底吃什么配置，再讲服务端文件和 Java，然后是两条开服路线怎么选，最后是价格和优惠怎么算。

## ATM10 服务器为什么比普通 MC 服更吃配置

ATM10 是 NeoForge 生态的整合包，跑在 Minecraft 1.21.1 上，服务端不能只用原版或 Paper 那套逻辑。官方的服务端包启动时会自己装 NeoForge，默认内存参数写在 `user_jvm_args.txt` 里，出厂值是 `-Xms4G -Xmx8G`——注意这是**整合包作者给的保底值，不是推荐值**。

几个硬性条件：

- **Java 21**。ATM10 的服务端脚本在 Java 版本不对时会直接报错退出，装 Java 17 或 8 是开不起来的。
- **正版验证**。默认开着的 `online-mode` 需要正版账号，如果朋友里有离线版玩家，得手动改。
- **服务端包体积在 1GB 以上**。以 8.2 版为例，`ServerFiles-8.2.zip` 大约 1.1GB，第一次启动装 NeoForge 的时间会明显比普通服长。

打包资源里带的联机功能也挺关键：FTB Teams 组队、FTB Chunks 圈地保护、FTB Quests 团队共享任务进度、Waystones 共享传送点。这些意味着 ATM10 不是"能进去就行"的服——几个人一起玩，任务和圈地必须靠一套常驻服务端撑着，本地开个房间那种玩法基本不成立。

## ATM10 服务器要多少内存和 CPU：按人数分档

社区整理的硬件参考大致是这样（不同来源在内存上略有出入，下面取的是较保守的区间）：

| 组件 | 2–5 人 | 5–15 人 | 15 人以上 |
| --- | --- | --- | --- |
| Java | 21 | 21 | 21 |
| 内存 | 10–12 GB 起 | 12–16 GB | 16 GB 以上 |
| CPU | 4 核 / 3.5GHz+ | 6 核 / 3.8GHz+ | 8 核 / 4.0GHz+ |
| 硬盘 | NVMe SSD 30 GB | NVMe SSD 50 GB | NVMe SSD 100 GB+ |
| 带宽 | 100 Mbps | 250 Mbps+ | 1 Gbps |

有两个容易忽略的点。

一是**堆内存要留头**。假设你买了 16G 的机器，把 `-Xmx` 直接填 16G 会让 Java 以外的部分没内存可用，服务端反而更容易崩；填 13G 左右更稳。

二是**单核比核心数重要**。Minecraft 服务端的多核优化一直很差，模组加载、区块生成、红石和机器运算都压在少数几个线程上。所以同样标"4核8G"，一台 5900X / 14900K 的机器和一台低主频至强，实际体验能差出一截。

## 第一步：服务端文件必须和客户端版本对齐

这一步做错，后面全白搭。

去 CurseForge 的 All the Mods 10 页面，进 Files 标签，**下载 Server Files，不是客户端包**。客户端整合包里有一批只该装在客户端上的 mod，直接扔进服务端会各种报错甚至起不来。

版本要和朋友们在启动器里装的完全一致。ATM10 官方版本号一直在更新，服务端包和客户端包对不上时，最常见的表现是能连上但瞬间被踢，或者提示缺失 mod。

## 第二步：Java 21、EULA、启动参数，三个必改的地方

第一次启动请按顺序做：

1. 运行 `startserver.sh`（Linux）或 `startserver.bat`（Windows），它会自动下载并安装对应版本的 NeoForge。**第一次会跑很久，中途别关窗口。**
2. 装完后脚本会停下来，因为 EULA 还没同意。打开 `eula.txt`，把 `false` 改成 `true`。
3. 回到 `user_jvm_args.txt`，按机器实际内存调 `-Xmx`。16G 的机器填 13G 上下，8G 的机器填 6G 左右。
4. 再跑一次启动脚本，正常情况 3 到 5 分钟能进到可连接状态。

顺手可以在 `server.properties` 里调几个值：视距（`view-distance`）8–10、模拟距离（`simulation-distance`）6–8、`spawn-protection` 设成 0（保护出生点这件事交给 FTB Chunks 更实用）、`max-tick-time` 拉到 120000。另外别动 `server-ip` 那一行，改成具体 IP 有可能直接导致服务端起不来。

## 第三步：两条开服路线，选哪条看你会不会碰命令行

### 路线一：面板服，网页点几下就开起来

适合不想学 Linux 的人。国内做这块比较久的是雨云，游戏云产品线里有两套面板：

- **雨云面板**：自研、跑在 K8s 集群上，支持一键开服、CPU 机型切换（目前有 i9 14900KS 和 Platinum 8259CL 可选）、可视化管理、备份和 MySQL，配置可以在面板里弹性升降级。
- **MCSM 面板**：官方页面上标注为"免费领取"，全中文，支持可视化文件管理和 SFTP。

这里面有个对 ATM10 很关键的细节：**一键开服列表里虽然直接有 NeoForge 服务端，但那装出来的是干净的 NeoForge 服，不是整合包。** ATM10 这种带 mod、config、kubejs 的包，正确做法是选面板提供的**纯 Java 环境（JDK 21）**，把 1GB 多的 ServerFiles 压缩包整个传上去解压，再改启动参数——这样 NeoForge 版本、内存分配、正版验证开关全在你自己手上。

另外 NAT 机型一般能开 15 个端口映射，MC 用 25565 一个就够，剩下留给 MCSM 的 23333 和 24444。

### 路线二：买台 VPS，自己想装什么都行

适合会用 SSH、或者以后打算同时跑别的东西（网站、机器人、别的游戏服）的人。雨云的游戏云 VPS 和普通云服务器都属于这一类，区别主要在 CPU 定位：游戏云用的是高主频 U，普通云服务器偏通用。

代价是环境全要自己来：装 Java 21、配 Docker、开防火墙端口、建开机自启。省下来的钱换来的是折腾时间，值不值看你自己的情况。

## 配置怎么选：直接给结论

按人数往下套，不用纠结：

- **就两三个人玩**：进阶级 4核 8G，内存往上抬到 12G 左右。这是能吃下 ATM10 又能省钱的档位。入门级 2核 4G 只适合先跑跑流程，长期玩会卡。
- **五到十个人，或者你打算跑大型机器、预生成地图**：超高端 6核 12G 起步，内存再加。ATM10 的机器自动化内容吃内存比吃 CPU 更狠。
- **只想试两小时看看能不能开起来**：先用低档 + 动态计费，或者直接试用。

另外计费模式值得单独提一句。**固定计费**是月租制，适合天天开着的服；**动态计费**按 CPU 实际消耗日结，服务器闲下来的时候费用也会降下来，适合只有周末凑齐人的小圈子。面板服还支持按天计费。这个选择不像配置那么显眼，但一个月下来能差出不少钱。

## ATM10 联机时值得开的几个设置

服开起来只是开始，这几项直接影响后面玩得爽不爽：

- **先组队再圈地**。`/ftbteams party create` 建队，再用 FTB Chunks 圈地。没圈的地方任何人都能挖，包括你的机器和箱子。
- **Waystones 建公共网络**。任何一个玩家激活的传送石，全服都能用。团队几个基地之间拉一条传送网，比互相跑图省事得多。
- **降视距比加内存便宜**。TPS 掉了先别急着升级配置，把 `view-distance` 从 10 降到 8、`simulation-distance` 降到 6，效果通常立竿见影。
- **少堆巨型机器**。整合包服最典型的卡顿来源就是无上限的刷怪塔和矿物处理链，服务器要跟着每个人加载的区块算一遍。

## 常见问题

**ATM10 的服务端文件要花钱买吗？**
不用。官方服务端包在 CurseForge / Modrinth 上免费下载，和你付的钱没关系。你花的钱是服务器硬件和带宽。

**4核 8G 够开 ATM10 吗？**
两三个人、不折腾大型机器，够。但内存最好抬到 12G 以上。4G 内存跑 ATM10 会一直卡在加载阶段，这个坑很常见。

**能先试用再买长期吗？**
可以。1 元试用一天，加上 7 天无理由退款，足够验证一遍完整流程。建议试用时就按最终想买的配置去试，别用最低配试完再猜高配行不行。

**为什么服务端第一次启动特别慢？**
因为第一次要下载并安装 NeoForge，同时生成模组配置文件。ATM10 这个体量的包，3 到 5 分钟属于正常，中途强制关窗口会导致安装不完整，需要删掉下载缓存重来。

**服务器卡顿、TPS 掉到个位数怎么办？**
按这个顺序排查：先降视距和模拟距离，再确认 `-Xmx` 有没有吃满你买的内存（默认 8G 是最常见的浪费），然后看有没有人搭了失控的自动农场，最后才是考虑升级配置。前两项不用花钱。

写在最后：ATM10 这类整合包服务器的成本，一半在硬件，一半在选错的配置上。先用高频 CPU 机型 + 12G 以上内存把服开稳，再按实际人数决定要不要往下调——比反过来省事得多。
